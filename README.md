Career Wave Server

A Node.js + Express backend application for a job portal system with authentication, job management, and application tracking.

Features

JWT Authentication (Cookie-based)
Firebase Token Verification
Job Posting System
Job Application System
Application Count per Job
Protected Routes (JWT + Firebase)
Modular Architecture (Routes, Controllers, Services)

Tech Stack

Node.js
Express.js
MongoDB
Firebase Admin SDK
JWT (jsonwebtoken)
Cookie Parser
CORS
